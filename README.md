Agente RAG con Gemini - Challenge Alura

## Descripción

Este proyecto consiste en un agente conversacional desarrollado como parte del Challenge de Alura.

El agente utiliza un documento PDF sobre Oracle Cloud Infrastructure Fundamentals como base de conocimiento para responder preguntas del usuario mediante inteligencia artificial.

## Tecnologías utilizadas

- Python 3.12
- Streamlit
- Google Gemini API
- FAISS
- PyPDF

## Funcionalidades

- Carga un documento PDF.
- Procesa el contenido para realizar búsquedas.
- Responde preguntas en lenguaje natural.
- Interfaz web desarrollada con Streamlit.
